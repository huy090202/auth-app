# SEO for authgatehq.com Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every public page of auth-app is a prerendered HTML document in its own language (EN at the root, VI under `/vi`), with a new landing page, head tags, a sitemap and robots.txt. The demo is noindex.

**Architecture:**
- The language moves from localStorage to the URL for the landing and docs pages.
- A landing page joins the router.
- A Vite SSR build plus a prerender script writes `dist/<path>/index.html` for every public route, with per-page head tags, and also writes `sitemap.xml` and `robots.txt`.
- CloudFront's `SpaRewrite` maps public paths to those files, using a `DocSlugs` parameter, and sends everything else to the SPA shell.

**Tech Stack:** React 19, react-router 7, Mantine 7, Vite 6 (client and SSR builds), vitest, node:test for the CloudFront Function, SAM, bash.

**Spec:** `docs/superpowers/specs/2026-11-23-seo-design.md`. Mockup: `docs/superpowers/specs/2026-11-23-seo-landing-mockup.html`.

## Global Constraints

- Site origin: `VITE_SITE_URL`, default `https://authgatehq.com`. The canonical and every absolute URL use it, with no trailing slash on the origin. Paths follow the URL table below.
- URLs:

  | Page | EN | VI |
  |---|---|---|
  | Landing | `/` | `/vi/` |
  | Docs | `/docs/<slug>` | `/vi/docs/<slug>` |

  The demo stays on `/app/...` and is never prerendered. Its shell `index.html` has `<meta name="robots" content="noindex">`.
- `hreflang` values: `en`, `vi` and `x-default`, where `x-default` points at the EN URL.
- `og:image` is `<site>/og.png`, 1200×630. `og:locale` is `en_US` or `vi_VN`.
- Descriptions are at most 160 characters, cut at a word boundary, with an ellipsis added only when cut.
- GitHub link: `https://github.com/huy090202/auth-gate`. Portal sign-up: the existing `portalSignUpUrl`.
- The browser starts with `createRoot`, never `hydrateRoot`.
- No new runtime dependency in `app/`. Dev dependencies are allowed only if a step names them.
- English in code and commits. VI copy is natural Vietnamese. Conventional Commits ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Gate: `pnpm run check`.

## Review Focus

1. A visitor with a stored `vi` opens `/docs/step-up`: they are moved to `/vi/docs/step-up` once, with no loop. A crawler, which has no storage, gets the EN page. Pinned in Task 1.
2. The EN/VI switch on a docs page with an anchor (`#hash`) or a query: it keeps both. Pinned in Task 1.
3. A docs slug that does not exist, in either language: it lands on that language's `what-it-is`, both in the SPA and through CloudFront (no S3 403). Pinned in Tasks 1 and 4.
4. A page title or description holding `"`, `<` or `&`: it is escaped in the head tags. Pinned in Task 3.
5. `/vi` without a trailing slash and `/vi/` both serve the VI landing. Pinned in Task 4.

### Task 1: The language in the URL

**Files:** `app/src/lib/i18n.ts` (+ test), `app/src/routes.tsx`, `app/src/App.tsx` (the header control), `app/src/brand.tsx` (the brand link), the docs links in `app/src/docs/*`, and wherever "Try it" or internal docs links are built.

**Interfaces:**
- Produces, in `app/src/lib/i18n.ts`:
  - `langFromPath(path: string): Lang`, which is `vi` when the path is `/vi` or starts with `/vi/`, else `en`;
  - `localePath(lang: Lang, path: string): string`, which adds the `/vi` prefix (`/` → `/vi/`);
  - `twinPath(path: string, to: Lang): string`, which keeps any search and hash.
- `useLang()` keeps its signature `[lang, setLang]`:
  - On the landing and docs routes, `lang` comes from the location, and `setLang` stores the choice, then navigates to `twinPath`.
  - Elsewhere (the demo), it behaves as today.
- Routes:
  - `/` and `/vi` (also `/vi/`) → `<Landing/>`. Use a placeholder component until Task 2.
  - `/docs/:page` and `/vi/docs/:page` → `<DocsPage/>`.
  - `/app/*` → the demo.
  - `*` → `<Navigate>` to the path's language `what-it-is`.
- `DocsPage` with an unknown slug navigates to the same language's `what-it-is`.
- The stored-preference redirect: on first render of a landing or docs route, if the stored language is `vi` and the path is EN, navigate once, with replace, to the twin. Never redirect VI to EN.

### Task 3: Prerender, head tags, sitemap and robots

**Files:** `app/src/entry-server.tsx`, `app/src/seo/routes.ts`, `app/src/seo/head.ts` (+ tests), `app/scripts/prerender.mjs`, `app/index.html` (noindex), `app/public/og.png`, `app/package.json` (`build`), and a test for the prerender output.

**Interfaces:**
- `publicRoutes(): Route[]`, where `Route = {path, lang, kind: 'landing'|'docs', slug?, title, description}`. It is built from the loader's pages and `landingStrings`.
- `describe(markdownBody: string): string` takes the first paragraph and applies the 160-character rule.
- `headFor(route: Route, site: string): string` returns the escaped tag markup of spec §5.
- `render(path: string): string` in `entry-server.tsx`: the app markup for a path, through react-router's static rendering inside the same providers as `main.tsx`.
- `build`: `tsc -b && vite build && vite build --ssr src/entry-server.tsx --outDir dist-ssr && node scripts/prerender.mjs`. The script:
  - reads `dist/index.html`;
  - for each route, replaces `<html lang="en">`, the `<title>` and the description, removes the shell's `noindex`, inserts `headFor` and puts `render(path)` inside `#root`;
  - writes `dist/<path>/index.html` (`/` → `dist/index.html` is NOT overwritten; write the EN landing to `dist/landing/index.html` and let CloudFront map `/` to it, see Task 4);
  - writes `dist/sitemap.xml` (every route, with `xhtml:link` alternates) and `dist/robots.txt` (`Allow: /`, `Disallow: /app/`, `Sitemap: <site>/sitemap.xml`);
  - deletes `dist-ssr`.
- `og.png`: make a 1200×630 PNG once, with a throwaway generator outside the repo, as auth-gate did for its email logo: the logo, the "AuthGate" wordmark and the hero line on the Canopy background. Commit only the PNG.
